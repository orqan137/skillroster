# Contributing

Thank you for improving SkillRoster.

1. Open an issue for a behavior change or schema evolution.
2. Create a focused branch and keep registry format changes backward-compatible within `v1alpha1`.
3. Run `pnpm typecheck`, `pnpm test:run`, and `pnpm build`.
4. Add tests for path handling, privacy fields, Git races, ranking changes, or hook preservation as appropriate.
5. Submit a pull request describing the user-visible outcome and any migration requirement.

Use Conventional Commit-style messages where practical. By contributing, you agree that your contribution is licensed under Apache License 2.0.
