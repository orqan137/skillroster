# Roadmap

Roadmap은 발표용 약속이 아니라 Issue와 Release로 추적하는 개발 순서임. 사용자 영향과 공개 형식의 안정성을 기준으로 변경함.

## v0.1.0 · 동작하는 해커톤 MVP

- Git-native 팀 초기화·참여와 전체 문서 검증
- 로컬 스킬 탐색, 발행, 작성자·동료 평가
- 프로젝트 태그 추천, skillset 연결, OpenCode sync
- 프롬프트·소스 비수집 실행 근거와 랭킹
- React 대시보드, CLI, Docker, 3개 OS CI
- Apache-2.0, 자동 의존성 라이선스 검사

## v0.2.0 · 설치와 팀 운영

- [npm 실행형 CLI와 OS별 독립 실행 파일](https://github.com/orqan137/skillroster/issues/6)
- [Codex·Claude Code evidence adapter](https://github.com/orqan137/skillroster/issues/7)
- [GitHub/GitLab 조직 신원 연결과 세분화된 project 권한](https://github.com/orqan137/skillroster/issues/8)
- registry migration·archive·restore 명령
- 접근성, [영문 문서와 실제 외부 contributor 온보딩](https://github.com/orqan137/skillroster/issues/9)

## v1.0.0 · 안정 형식

- `v1alpha1` 사용 피드백을 반영한 호환성 정책
- 서명된 skill release와 provenance 검증
- 대규모 팀의 merge conflict와 순위 성능 검증
- 조직 내부 장기 운영을 위한 백업·감사 가이드

각 항목은 GitHub Issue에서 수용 기준과 보안 영향을 먼저 정의함. 완료되지 않은 항목은 README와 발표에서 현재 기능으로 표기하지 않음.
